# Mi sitio web personal
Este proyecto que nació inicialmente para conocer y aprender nginx, se terminó convirtiendo en mi sitio web personal, donde aprendí a construir un sitio web desde cero y a administrar sistemas.

## Tecnologías utilizadas
* Contenedores: Podman
* Hospedaje: AWS (EC2)
* Certificado SSL: Let's Encrypt / Certbot
* Control de Versiones: Git
